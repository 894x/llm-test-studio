# Kimi-K3 audit cases

This suite translates the supplied 2026-08-14 Kimi-K3 report into repository-owned `case.json` definitions.

- 14 HTTP/SSE cases are currently executable through `api-audit`.
- Multimodal case definitions are temporarily marked `disabled` and excluded even from `--all-cases`; their deterministic fixtures are retained for later re-enablement.
- Thinking switch and compatibility-alias cases are disabled because Kimi-K3 officially requires thinking to remain enabled. Only the no-switch default-on baseline remains executable.
- Deterministic fixtures are generated by `tools/api-audit/fixtures/kimi-k3/generate_number_media.py` with an OpenCV/Numpy frame buffer: the PNG contains `7`, while the MP4 shows `3`, `7`, `4` in order.
- File-ID inputs require IDs created in the target provider account; the self-contained suite covers the base64 branch and does not fabricate file IDs that would create deterministic false failures.
- Kimi-K3's fixed sampling parameters are treated as an integration policy rather than a provider defect: caller values are ignored and official defaults are used. The suite keeps one no-sampling-parameter baseline instead of duplicate fixed/rejected-value cases, and the generated report explains this policy at the top.
- The report's `must.tool_choice`, `must.thinking_switch`, and `must.structured_output` rows are derived aggregates, so they are not duplicated as no-op cases.
- The report's `note.content_filter` row requires supplier-side manual confirmation and is not represented as an automated pass.
- `load-profile-32k.json` records the report's 32K load scenario, but the regular `api-audit` run does not automatically execute that paid 160-request workload.

The compatibility cases intentionally preserve the report's observed gateway behavior. In particular, remote visual URLs and `thinking.type=disabled` may differ from the current first-party Kimi API contract.

```powershell
go build -o .\bin\api-audit.exe .\cmd\api-audit
.\bin\api-audit.exe list --suite kimi-k3

# Default non-stream usage smoke case; model defaults to kimi-k3.
$env:API_AUDIT_API_KEY = "<secret>"
.\bin\api-audit.exe run --suite kimi-k3 --base-url "https://gateway.example"

# Inspect the complete suite without submitting requests.
.\bin\api-audit.exe run --suite kimi-k3 --base-url "https://gateway.example" --all-cases --dry-run
```
