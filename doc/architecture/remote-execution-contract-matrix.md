# 远程执行当前提交契约与验证矩阵

范围：自有 runner 管理协议的 JobSpec、ExecutionTarget、Submission、asset manifest、事件和控制命令；规则来源为[远程执行方案](remote-execution-plan.md)，不是提供商参数。2026-10-17 按 `ef9c352` 基线及本轮仅测试增量复核源码和已有执行记录：T0 的 validator、SQLite、Core/Mock HTTP，与真实 SSH、systemd、独立桌面进程、OSStore 和付费渠道证据分别记录。本次文档审计没有为文档重复旧测试或重跑付费请求；下方新增T0负例在各轮实际执行通过，执行记录分轮列明。

`covered` 只表示该行选定的必需场景已有对应断言和执行记录，不表示所有层级均实跑；`partial` 保留具体断言缺口，`deferred` 表示用户已暂缓的文件、媒体、native_case 扩展。设计、构建、普通 HTTP 成功不能代替这些证据。当前状态以本节表格和末尾“本轮收尾审计”节为准；后面的带日期阶段记录保留当时事实，不将旧的 pending 或失败追认为当前结果。完整运行回执见[验证记录](remote-execution-validation.md)，用户可读摘要见[当前交付状态](remote-execution-status.md)。

结构清单：Submission 只有 job 与 secrets；job 包含 contract、job_id、node_installation_id、engine_build_id、target、kind、spec、assets；target 包含 kind、node_id；spec 恰有 run、performance、comparison 之一。秘密条目只有 slot 与 value，value 为 JSON base64 字节。asset 条目只有 ref、sha256、size、media_type。run 与 performance 直接复用 A1 至 A3 的准备值；comparison 包含 meta、plan、model、runs，复用 A4a 的整组准备值。

新字段没有历史默认或旧格式回退。assets 必须为数组，没有文件时显式传 []。本地和远程都携带执行宿主的安装身份与实际构建；不要求客户端自身构建与 runner 相同。本地 target 禁止 node_id，remote target 必须携带节点回读的共享 UUID。资产 ref 是 1 至 80 字节的小写字母数字及点、下划线、连字符，首字符须是字母数字；禁止任意文件路径。media_type 是无参数的规范小写 MIME 类型，最多 127 字节。

## JSON 传输字节边界

当前管理 JSON 使用正常 HTTP 内容协商。typed JSON 客户端显式请求 gzip；服务端仅在明确接受 gzip 时压缩，同一当前 JSON 也可使用 identity。此协商不改变管理契约、任务格式、canonical 文档或解码后的摘要，不选择历史实现。Node.Info 和报告下载仍请求 identity；Range 不能与 JSONGzip 同时设置，报告原字节、摘要及续传位置保持一致。

客户端分别限制线上压缩字节和解压后的文档：gzip wire 最多为该操作原字节上限加 64 KiB，解压后仍受原操作上限约束；普通管理JSON为30秒，events JSON为2分钟；同步Pass总预算5分钟、session2分钟不变。只接收单个 gzip member，CRC、截断、拖尾、重复或未知 Content-Encoding、长度不符和任一预算超限均拒绝。不能用 HTTP transport 的透明解压跳过 wire 校验。

TestJSONGzipPreservesCurrentTypedStateAndFixedErrors、TestReadJSONRejectsInvalidCompressedFramingAndBudgets、TestJSONGzipKeepsTransportErrorsSeparateAndDownloadIdentity、TestReportHTTPRangeStaysIdentityEvenWhenGzipIsRequested 与 TestJSONGzipRequiresExplicitAcceptableCoding 验证 typed/canonical 一致、固定错误、压缩边界、协商与 Range。合成大页面的压缩比测试只证明传输及 envelope，不代替真实领域进度、物理 SSH 或完整桌面验收。当前priority/tail/history调度已有H20/H21实现与测试；13项历史完整续传已证，大历史积压下新任务及时性的专门实跑仍保留。
