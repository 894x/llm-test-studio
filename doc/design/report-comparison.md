# 报告对比

报告页以已封存报告为对比对象。勾选 2–8 份功能或性能报告后打开对比；同一渠道的不同时间报告保留独立身份。报告详情的“与其他报告对比”将当前报告加入选择，并返回列表选择其他报告。选择可跨搜索保留，返回列表保留搜索和选择，清除选择只影响本次会话。

渠道批量测试沿用原有同计划、同模型、多渠道执行流程和任务控制。其子报告现在也独立显示和勾选；批量历史记录继续保留。整组报告均已同步且数量在对比范围内时，列表按钮与运行记录的直接入口均进入同一报告对比界面，提供基准选择和“仅看差异”；仍待归档或超过范围的批量记录继续使用分组查看与导出流程。直接打开的批量记录在归档齐全后自动进入对比界面，返回列表不会重新打开。两种视图共用窄列倾斜表头和“必过／容忍＋结果”单元格，顶部不重复显示各渠道的总状态或生成时间；读取中、等待归档及读取失败的提示仍保留。

## 对齐与差异

- Go 读取指定报告及其冻结快照，不使用当前目录、当前断言或渠道最新配置重算历史结论。
- 列使用报告 ID，表头展示冻结的渠道、模型及基准标记；基准选择项、展开详情及视觉导出的渠道标题同样不显示生成时间。渠道 ID 不作为列唯一键，原始报告时间继续保留在报告数据中。
- 渠道列采用适合“等级＋结果”的紧凑宽度，常规为 104px；用例名称列使用剩余空间并至少保留 220px，空间不足时进一步平分缩小渠道列。实际测量渠道与模型文字，只要任一可见渠道的文字宽于当前列内容区，该表全部渠道表头统一倾斜；全部容得下时统一水平。窗口缩放、字体及渠道折叠变化后重新判断，较长标题可悬浮或聚焦查看全文。2–8 份报告在受支持的桌面尺寸内无需横向滚动，展开后的各渠道详情按空间换行；复制图片与视觉导出沿用当前面板宽度和相同布局。
- 行按目标种类、稳定目标 ID、重复执行项及用例 ID 对齐。同一套件的多次执行独立保留；已有执行项 ID 可识别重排，独立计划中的新执行项按目标的出现次序配对。重排与新增同时发生时保留独立行，不允许覆盖同一报告的结果。
- 功能项比较冻结用例定义及修订、协议、参数、用例输入、负载、超时、轮询设置、SLA、预热和随机种子；性能项比较协议与已封存性能配置。模型与渠道是比较维度，执行时间和执行环境可在原报告查看，不由此推断因果关系。
- Go 继续计算新增失败、恢复通过、结果变化及测试条件变化，供“仅看差异”和 JSON 导出使用；矩阵单元格仅显示原报告冻结的用例等级“必过／容忍”和结果，不显示这些补充说明或重复的使用提示。条件不同时保留各自结论与数值，不提供差值。
- 缺测显示“未覆盖”，已记录但未执行显示“未执行”，均不合成为失败。无有效样本的指标不补零；差值仅对存在观测且名称、单位相同的指标计算，方向为本报告减基准报告，不生成总排名。
- 基准可切换，“仅看差异”使用 Go 的差异投影。渠道可独立折叠与展开，至少保留一列；同渠道的多份报告仍按报告 ID 独立控制，折叠不改变基准或差异计算。用例名称完整换行并保留一个详情展开入口，查看该行的完整指标、差值、请求、断言、协议证据或性能请求样本，可再次收起。复制图片及 HTML、PNG、PDF 复用当前筛选、可见渠道和用例展开状态，默认展示等级与结果；JSON 保留全部对比数据。批量分组折叠至单渠道时仍保持相同单元格布局。数据集评测报告继续使用自身报告阅读器，暂不加入此矩阵。

## 数据与兼容边界

当前本地发布标签包括 v0.1.0–v0.1.5。本功能是随桌面前后端一起发布的新增读取接口 `CompareReports(reportIDs, baselineID)`；不更改这些版本的公开 CLI、远程 runner 协议、Case/Suite/Plan 文件、原报告 JSON 或 SQLite 格式，也不扩大已有历史格式支持窗口。

对比视图为会话内状态，不创建持久化对比实体或复制原报告。新的对比 JSON 使用独立文件名 `llm-test-studio-report-comparison-<baseline-id>.json`，包含 schema 1、报告引用身份、读取时的详情和差异投影。HTML、PNG、PDF 及复制图片反映当前差异筛选及用例展开状态，渠道标题不显示时间；JSON 保留全部对比行及原报告生成时间。已有渠道分组 JSON 导出继续保留原格式。

不需要数据库迁移、历史数据转换或新增弃用期限。回退本功能不会丢失原报告，旧版本仍按其支持范围读取原工作区；对比选择不跨应用重启保存。其他版本自身已有的升级、降级与备份限制继续适用。

验证包括 Go 对齐、修订变化、同渠道历史、缺测、单位与样本边界、基准切换及不修改原数据测试；桌面绑定的输入拒绝、顺序和身份校验；实际 SQLite 归档读取；前端多选、跨筛选选择、差异视图、重试、导出及旧批量报告回归。浏览器样本仅证明界面行为，不代表用户工作区或真实提供商测试结果。
