# 模型与渠道映射的协议

模型保存非空、无重复的 `protocols` 列表。渠道保留默认 `protocol`，但默认协议不限制模型映射。
每条渠道模型映射保存上游模型名称和非空 `protocols` 列表；映射协议必须是该模型协议的子集。
同一渠道和模型只保存一条映射，编辑协议列表不改变映射标识或所属模型、渠道。

模型编辑允许增加协议、删除未被映射使用的协议。删除仍被映射使用的协议返回冲突，
需要先修改对应映射。校验在 Application Core 与持有跨进程目录锁的存储写入路径中执行。

快速测试显式选择协议，再选择该协议的套件。协议切换更新套件、输入参数和接口路径预览，
保留手动填写的模型、地址和临时密钥，清除绑定旧协议的历史凭据引用。
保存渠道的密钥仍由 Go 读取，不进入前端。输入已配置的上游模型时，所选协议必须属于
该渠道模型映射的协议列表；自由输入未配置的模型仍可用于临时测试。

计划与对比运行使用计划协议，并校验模型和映射均支持该协议。冻结的执行模型与渠道
保存此次使用的单个协议；执行不依赖渠道默认协议，也不转换外部提供商的协议。

## 当前格式与历史数据

模型命令、目录 DTO 和 `models.json` 的 `protocol` 字段已替换为 `protocols` 数组。
映射命令、目录 DTO、`channels.json` 的 `model_mappings` 和运行快照中的 `mapping`
必须包含 `protocols` 数组。渠道和套件的 `protocol` 字段仍表示单个默认或执行协议。

旧模型字段、缺少协议的旧映射和包含旧映射的历史运行、报告快照会被明确拒绝。
