# 用例维度与兼容性统计

用例已有必填、可自定义的 `dimension`，例如 `tools`、`protocol`、`multimodal`、
`parameters`、`cache`。本次复用现有字段，不改用例分类，也不修改请求、断言或套件成员。
用例页显示维度列，搜索同时匹配维度；编辑仍使用现有维度字段。

## 统计口径

- 维度来自封存报告 `plan_snapshot` 内的用例定义，不读取当前目录。之后编辑用例的维度
  不会改变已有运行的归属。
- 每个 `(entry_id, case_id)` 计一次。负载产生的多个请求不会增加用例权重；同一个用例
  在不同执行项中运行，保留每个执行项的独立结果。
- 复用报告用例明细已有的断言汇总：任一失败则用例失败，否则任一待判定则待判定，
  否则有通过则通过，其余有观测的用例为仅观察。没有测量结果的用例为未执行。
- 预热与检查点不参与断言汇总，性能项及未归属请求不参加维度统计。取消或中断的报告
  仅汇总已有观测，不能把部分通过解读为整个计划完成。
- `pass_rate_percent = passed_case_count / (passed_case_count + failed_case_count) * 100`。
  仅观察、待判定、未执行单列，不进入分母；没有可判定用例时为 `null`，界面显示 `—`。
  数据保留原始精度，界面最多显示两位小数。
- 此表反映断言验证情况；预期拒绝非法请求的用例可以通过。它不代表 HTTP 成功率，
  也不覆盖 SLA、必过／容忍策略或原有整份报告的结论。

报告总览左右分列、顶端对齐。左侧以“用例关键结果”标题组织四项单行统计和下方的用例
结果导航；右侧使用宽 460px 的 0–100% 通过率雷达图，剩余宽度留给结果摘要。
不再显示图下提示文字，统计口径保留在图表可访问说明中。结果色块固定为 20px，
使用 Flex 自动换行，按容器宽度计算统一的横向间距，最小间距及行距为 4px。
最后一行从左侧继续按相同列位置排列，不单独拉伸间距；窗口缩放时重新计算。
用例导航选中、定位和键盘操作保持。在执行项的用例表
增加维度列。维度可悬停或通过键盘聚焦查看原始计数；无可判定结果的维度不绘制数值，
不以 0% 填补空值，也不跨缺失轴填充面积。只有一个或两个维度时展示已有轴线与数据点，
不补造分类。长标签按分隔符换行，过长标签在图内省略但悬浮说明保留完整内容。
内置维度名称与悬浮明细跟随界面中英文实时切换，桌面视觉导出使用当前语言；自定义
维度保留原名，分组标识、运行快照及机器可读数据不翻译、不改写。
桌面 HTML、PNG、PDF 视觉导出复用相同雷达组件；Go JSON、HTML、PNG、PDF 导出保留
相同统计口径。

## 发布与兼容性

计划随下一次功能发布交付。报告详情／JSON 导出沿用 schema 1，增加可选
`dimension_statistics` 数组及用例明细 `dimension`。旧详情缺少新增字段时仍可读取，
不填造分类或统计。提供字段时严格检查类型、维度非空、计数合计、重复维度及比例范围。
新增读取模型不写入数据库或封存报告；既有字段、原报告结论与导出原始报告均保留。
历史数据支持窗口及不支持的版本沿用 [兼容性政策](../compatibility-policy.md)。

Case schema 2/3、Suite schema 1、Plan、CLI 选项和退出码、runner 协议及能力、数据库
结构与版本均未变更。桌面前后端一起更新即可，不需要数据迁移或重新执行测试；历史
报告使用其已有快照与观测生成读取统计。没有新增弃用或移除计划。本功能没有新增
持久化格式，降级无需专项转换；其他变更的工作区备份与匹配版本要求保持。

## 验证

自动化回归覆盖按用例而非请求计数、跨执行项重复用例、通过／失败／仅观察／待判定／
未执行、预热和检查点排除、性能项排除、自定义维度及排序、空统计、旧详情读取、
非法字段拒绝且输入不变。使用真实旧报告 fixture
`legacy-sla-precision-c561055d.json` 验证冻结维度、原始历史失败、JSON 导出原报告
及输入字节均保留，并检查中英文 HTML 和 PNG／PDF 共用的绘图内容。

前端回归覆盖维度搜索、报告维度列、Core 统计展示、无可判定结果、可访问比例标签和
视觉导出。浏览器开发样本仅用于呈现验证，不代表已验收原生 Wails 或用户数据库。
