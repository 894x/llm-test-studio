# 桌面软件内更新

桌面端继续从 `894x/llm-test-studio` 的 GitHub Releases 获取完整安装包。
界面设置中的“软件更新”提供检查、下载、取消、跳过当前版本和安装入口；
发现可用更新后标题栏提供入口。首次安装带此功能的版本仍需手动下载。

## 用户流程

- 默认每次启动自动检查一次稳定版本，可以关闭；手动检查不受此开关影响。
  检查失败不影响工作区使用，不把网络失败显示为“已是最新版本”。
- 只自动选择严格 `vMAJOR.MINOR.PATCH` 且高于当前版本的稳定版；不选择草稿、
  预发布或更低版本。开发版及不支持的平台禁用更新，仍提供发布页面入口。
- 跳过版本只关闭该版本的更新提示，仍可手动下载；更新版本会再次提示。
- 下载在 Go 后台执行，关闭面板继续下载。取消或失败删除本次未验证的暂存文件；
  重试重新完整下载，首版不做断点续传或差分更新。退出软件会取消下载。
- Windows 安装版通过同目录 `uninstall.exe` 识别，下载对应 NSIS 安装器；
  便携版下载 ZIP。确认保存编辑后才能“重启并更新”。安装版由 Windows 显示
  UAC，安装器静默覆盖当前安装目录，助手等待安装结束再启动应用。
  安装器超时或无法确认是否退出时不会启动应用，避免与安装器继续写文件竞争。
- Windows 便携版仅接受包含一个 `llm-test-studio.exe` 的 ZIP。助手保留旧程序为
  `.previous-install-*`，再发布完整的新程序。文件替换失败恢复旧程序；新版进程
  无法启动且尚未执行时可恢复旧程序。成功启动后不自动回退二进制。
- macOS 首版下载并校验 DMG，通过系统打开安装包，由用户完成拖放安装；
  不声称支持静默替换 `.app`，也不会因此自动退出当前应用。

## 任务、退出及数据边界

安装前阻止新的桌面调用租约，并检查已经获得租约的操作、数据集执行／准备／
下载、普通 Run 以及分页 Job 状态。存在活动任务、待确认提交、无法读取的状态
或超出有界检查范围时延后安装，不自动取消任务。任务结束后用户再次点击安装。

安装助手由当前程序的临时副本运行，在 Wails、凭据和数据库初始化之前识别
专用参数。助手验证私有暂存目录中的计划与载荷，先向父进程报告就绪；只有
Wails 正常返回且共享 Shutdown 成功后，父进程才通过管道授权安装。助手等待
父进程实际退出后才进行替换。关闭超时、未收到授权或载荷校验失败均不安装。

更新器不打开、删除或重置数据库，不操作渠道、凭据或历史报告。新版启动继续
走共享工作区版本预检、已交付的备份及迁移链。支持的升级来源沿用
[兼容性政策](../compatibility-policy.md)，不扩大到旧 `v0.0.01` schema 7。
桌面端更新不会自动更新独立 runner；协议和能力组合仍由既有协商门禁判断。
需要同步更新 runner 的版本必须在发布说明中说明顺序。

旧程序备份不是工作区备份。新程序启动后可能完成数据迁移，因此降级必须遵循
对应发布的恢复说明，必要时恢复更新前的工作区备份及匹配二进制；恢复旧备份
不包含之后新增的数据。助手不能根据“进程已启动”推断工作区迁移成功。

## 下载信任及发布流程

更新源固定为本仓库的 GitHub API 和 Releases 地址，不接受前端提供的下载 URL、
文件路径、安装命令或目标版本。仅允许 HTTPS；重定向仅允许 GitHub 及其已知
Release 资产域名，不发送令牌。超时、响应文档和压缩／解压载荷均有上限。

候选资产必须有精确名称和本次 tag 的仓库下载地址，且有唯一 SHA256SUMS 条目；
如果 GitHub 返回资产 digest，必须与其一致。下载验证实际长度与 SHA-256，安装
前再次校验已下载文件；便携包还校验归档结构、解压大小和载荷摘要。

此版本信任 GitHub HTTPS、仓库发布权限和同源校验信息。SHA-256 提供下载完整性，
不等于独立发布签名或操作系统代码签名。此改动不创建私钥，不宣称 Windows
Authenticode 或 Apple 签名／公证已经完成；正式发布前仍需按发布要求验收。

发布工作流先上传所有资产及校验文件到草稿，再发布完整 Release。预发布明确
标记为 prerelease，不设为 latest；已公开版本禁止覆盖资产，需要新建版本 tag。
这避免更新器把正在上传的发布当作完整版本。已有 Release 不会被本地开发修改。

## 新增持久化格式

`<用户配置目录>/llm-test-studio/updates/preferences.json` 是新增的独立 schema 1：

```json
{"schema_version":1,"auto_check":true,"skipped_version":""}
```

首次无文件时使用默认值；未知版本、缺失字段、未知字段、无效类型或损坏内容
明确拒绝且不覆写原文件。写入使用同目录暂存、同步和替换。该文件不包含密钥。
原有用户配置、Case/Suite/Plan、SQLite、CLI、runner 协议及历史报告格式不变，
无需为此增加数据库迁移。桌面 DTO／绑定和当前前端随同一安装包一起更新，
没有历史内部绑定别名或移除已发布接口。

下载、安装计划、旧程序副本与安装结果保留在 `updates/download-*` 暂存目录。
安装结果不包含工作区内容；失败后可通过软件内重试检查和重新下载恢复，
无法启动的软件使用 GitHub 发布页的完整安装包修复。首版不自动清理成功安装
后的旧程序备份，以免替代用户的恢复决策；可在确认新版可用后手动移除。

## 验证范围

回归覆盖版本比较、未知偏好无修改拒绝、跳过与关闭自动检查、发布资产缺失／
重复／跨仓库地址／digest 冲突、下载篡改与截断、取消和重试、退出取消、归档
越界、替换失败恢复、安装前再次校验摘要和一次性退出授权。Windows 集成测试
在独立临时目录运行真实助手，等待父进程退出、替换程序、保留旧程序并重新
启动；不访问真实用户工作区，不安装系统级软件。

前端回归覆盖严格 DTO、StrictMode 下单次自动检查、下载与取消、进度、跳过、
安装确认、活动任务阻止安装、macOS 手动交接和原始错误隔离。正式发布仍需
使用实际签名产物验收 Windows UAC／安装版，以及 macOS 原生 DMG 拖放升级。
